# HamClock-Next

HamClock-Next is an amateur radio dashboard that puts space weather, propagation, [DX spots](Glossary.md#dx--dx-cluster--spot), maps, and useful operating tools on one screen.

It continues the original HamClock by Elwood Downey, WB0OEW (Silent Key, 29 January 2026), and adds browser support, a modern display engine, and a flexible six-pane layout.

![Full dashboard overview](images/map_looks/robinson_clouds_dark.png)

---

## Key Features

- **64 widgets** for space weather, propagation, DX spots, weather, tracking, clocks, and utilities
- **Six rotatable panes** that can each show one widget or cycle through several
- **Map overlays** for MUF, VOACAP, cloud cover, aurora, and more
- **Presets** to save and restore a complete screen setup
- **Runs on Linux, macOS, Windows, and in a browser**
- **K key** to highlight clickable areas
- **? key** for built-in help
